# Dgg-Chat-Popout

Chrome extension: destiny.gg chat and linkers.ooo side by side in a toolbar popup.

## Install

1. Download `Dgg-Chat-Popout.zip` from [Releases](../../releases/latest).
2. Unzip it.
3. Go to `chrome://extensions`, turn on **Developer mode**, click **Load unpacked** and pick the folder.

Works in Chrome, Vivaldi, Helium and other Chromium browsers.
